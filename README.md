# Pyoverdines

*Analysis and comparisons between known pyoverdines*

## Overview

This repo contains a list of manually curated pyoverdines and data 
analysis of diversity. The data is a compilation from existing lists and manual 
searches with a full description in the data folder. 

## Get started

To repeat the data analysis, a conda enviroment is the easiest set up. This can 
be set up using the provided `environment.yml`. To set this up, follow these 
steps:

Clone the repository:
```
git clone https://github.com/MarkCalcott/pyoverdine_review
cd pyoverdine_review
```

Create and activate the conda environment
```
conda env create -f environment.yml
```

Then open the Jupyter notebook in the notebooks folder and run the cells.
